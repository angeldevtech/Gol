**Gol** es una aplicación para Android TV y dispositivos móviles desarrollada con Kotlin y Jetpack Compose. Te permite ver eventos deportivos con horarios ajustados automáticamente a la **zona horaria local del Perú**. Es tu guía personalizada para eventos deportivos, adaptada a tu pantalla y a tu tiempo.

## 🧩 Funcionalidades

* 📺 Soporte nativo para **Android TV** y **móviles**
* ⏰ Horarios ajustados automáticamente a la **hora local del Perú (GMT-5)**
* 🏅 Enfoque en **eventos deportivos** de diversas categorías
* ✨ Interfaz moderna usando **Jetpack Compose**

## 🏗️ Instrucciones de compilación

Asegúrate de tener instalada la última versión de **Android Studio** y **Kotlin**.

### Requisitos

* Android Studio Giraffe o superior
* Kotlin 2.1.21
* Android SDK 35 (minSdk 28)

### Clonar y compilar

```bash
git clone https://github.com/angeldevtech/Gol.git
cd gol
```

Ábrelo en Android Studio y haz clic en **Run**.

## ⚠️ Aviso legal

Este es un **proyecto hobby** y **no está afiliado a ningún canal de televisión, proveedor de contenido ni liga deportiva**. Todo el contenido es obtenido desde una API pública.

* **Propósito**: Gol es un cliente que puede conectarse a endpoints de una API y mostrar el contenido en un reproductor. Esta aplicación está diseñada solo con fines educativos.
* **Política de contenido**: Gol no mantiene ni aloja servicios de streaming ni contenido con derechos de autor.
