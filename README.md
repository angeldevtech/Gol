**Gol** is a Kotlin + Jetpack Compose app for Android TV and mobile that helps you watch sports events with times adjusted to **Peru's local timezone**. It's your personalized guide for upcoming sports, tailored to your screen and time.

## 🧩 Features

* 📺 Native support for **Android TV** and **mobile**
* ⏰ Event times auto-adjusted to **Peru time (GMT-5)**
* 🏅 Focus on **sports events** across multiple categories
* ✨ Modern UI with **Jetpack Compose**

## 🏗️ Build Instructions

Make sure you have the latest **Android Studio** and **Kotlin** installed.

### Requirements

* Android Studio Giraffe or newer
* Kotlin 2.1.21
* Android SDK 35 (minSdk 28)

### Clone & Build

```bash
git clone https://github.com/angeldevtech/Gol.git
cd gol
```

Open in Android Studio and click **Run**.
